# Рядом — доска объявлений

Запуск на компьютере: установите Node.js 22.13+, затем `npm install` и `npm start`, откройте http://localhost:3000

Публикация на Render: загрузите все файлы в репозиторий GitHub, затем Render → New → Blueprint.
Админ: логин root, пароль — в Render, раздел Environment, переменная ADMIN_PASSWORD
(на компьютере без настроек: admin12345). Тестовый юзер: anna / user12345.
Код подтверждения при регистрации показывается на экране (демо-режим).
